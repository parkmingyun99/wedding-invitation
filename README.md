# Wedding Invitation Mobile App

This project is a mobile invitation app for the wedding of 박민균, scheduled for January 17, 2027. The app is built using React and provides an interactive and visually appealing way to invite guests.

## Project Structure

```
wedding-invitation
├── src
│   ├── components
│   │   ├── Hero.tsx
│   │   ├── Gallery.tsx
│   │   ├── EventInfo.tsx
│   │   ├── Location.tsx
│   │   └── Contact.tsx
│   ├── assets
│   ├── App.tsx
│   ├── main.tsx
│   └── styles.css
├── public
├── package.json
├── tsconfig.json
├── vite.config.ts
└── README.md
```

## Features

- **Hero Section**: Displays the main title and theme of the wedding invitation.
- **Gallery**: Showcases images related to the wedding, including pre-wedding events and couple photos.
- **Event Information**: Provides details about the wedding date, time, and schedule.
- **Location**: Displays venue information, including the address and an embedded map.
- **Contact Information**: Allows guests to RSVP or ask questions.

## Getting Started

To get started with the project, follow these steps:

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd wedding-invitation
   ```

3. Install the dependencies:
   ```
   npm install
   ```

4. Start the development server:
   ```
   npm run dev
   ```

5. Open your browser and go to `http://localhost:3000` to view the app.
